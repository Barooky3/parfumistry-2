

# ProfParfums — Light & Airy Fragrance Shop

A unique fragrance affiliate shop with a fresh, light aesthetic that's completely different from traditional dark luxury perfume sites.

---

## 🎨 Visual Identity (Completely Unique from AromaEU)

### Color Palette
- **Background:** Soft cream (#FDFCFA) and warm white (#F8F6F3)
- **Primary:** Soft lavender (#A78BBA) — fresh and unexpected for fragrance
- **Secondary:** Dusty rose (#D4A5A5) — warm and inviting
- **Accent:** Soft teal (#7EB8B8) — modern freshness
- **Text:** Warm charcoal (#3D3D3D) — readable without harshness
- **Cards:** Pure white with soft shadows

### Typography
- **Logo/Headings:** Elegant modern serif (Cormorant Garamond) — refined but light
- **Body:** Clean humanist sans-serif (Inter) — modern and readable
- Generous whitespace and line-height throughout

### Design Contrast from AromaEU
| AromaEU | ProfParfums |
|---------|-------------|
| Dark background | Light cream background |
| Gold/yellow accents | Lavender/teal accents |
| Heavy imagery | Clean, airy layouts |
| Traditional luxury | Fresh, modern premium |
| Full-width hero | Centered, contained design |

## 🛒 Cart & Checkout Flow

1. User browses products → clicks "Add to Cart"
2. Cart drawer opens showing items
3. User can adjust quantities or remove items
4. Clicks "Checkout" → goes to checkout page
5. Reviews order summary
6. Clicks "Complete Purchase" → redirected to your affiliate seller link (new tab)

## 📱 Responsive Design

- **Desktop:** 4-column grid, full navigation

## ✨ Animations & Polish

- Subtle fade-in on scroll
- Smooth cart drawer slide animation
- Gentle hover effects on cards and buttons
- Soft loading states
- Toast notifications for cart actions

## 🚀 Technical Approach

- Static product data (3 fragrances to start, easily expandable)
- Cart state managed with React Context + localStorage
- Responsive with Tailwind CSS
- All affiliate links open in new tabs
- Currency display (EUR, configurable)
